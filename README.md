My project is about Akan names. Akan names are traditional Ghanaian names given to children based on the day of the week on which they were born. My website allows users to enter their date of birth, including the day, month, and year, and select their gender to find their Akan name.

I used HTML to:

Create the heading and introduction of my website.
Add input fields for the day, month, and year of birth.
Add options for users to select their gender.
Create a button that users click to generate their Akan name.
Add a section where the generated Akan name is displayed

I used CSS to:

Add colours and background styles.
Style the headings, buttons, and input fields.
Adjust the spacing and alignment of the elements.
Make the website look neat and organized.
Improve the appearance of the website on different screen sizes.

I used JavaScript to:

Collect the day, month, and year entered by the user.
Collect the selected gender.
Check whether the user has entered valid information.
Calculate the day of the week on which the user was born using the date of birth.
Match the calculated day with the correct Akan name for the selected gender.
Display the Akan name to the user.

 Conclusio
   
In conclusion, I used HTML to create the structure of my Akan Names website, CSS to style it, and JavaScript to calculate the day of birth and generate the appropriate Akan name. This project helped me understand how HTML, CSS, and JavaScript work together to create an interactive website.
